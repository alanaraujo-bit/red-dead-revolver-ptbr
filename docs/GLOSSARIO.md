# Glossário e estilo

Regras que mantêm a tradução consistente. Na dúvida, siga o que já está no jogo e pergunte numa issue.

- "você" informal; imperativo nas dicas; tom de faroeste.
- Mantidos em inglês: Dead Eye, Lockblast, Battle Royale, nomes de cidades e lugares
  (Brimstone, Widow's Patch, Bear Mountain, Hell Pass, Sunset Canyon...), nomes de pessoas.
- Mr. → Sr.; Sheriff → Xerife; Governor → Governador; Showdown (modo) → Confronto.
- place locks → marcar os alvos; draw → sacar; grab (arma) → pegar; reticle → mira;
  bounty → recompensa; bounty hunter → caçador de recompensas; shotgun → escopeta.
- Apelidos entre aspas são traduzidos ("Cachinhos" Shaw, "Ouriço" Thornton); vilões citados em
  frases: Chris, o Feio; Josh, o Porco.
- Símbolos `½ ¼ ¾ º † ‡ • ‣` são ícones de botão: preservar sempre. "…" vira "..." (glifo ausente).

## Regra de ouro das imagens

Só traduzir o que um jogador americano consegue ler no original. Texto miúdo ilegível fica como enfeite: nunca inventar texto novo.
